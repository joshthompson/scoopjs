# Decisions

The decisions that shape ScoopJS, recorded as ADRs (architecture decision
records): what was decided, what else was considered, and what follows from
it. They live in the repo's `docs/adr/` folder.

| ADR | Decision |
|---|---|
| [0001](/adr/0001-plugins-are-composition) | Plugins are built on Core's API, not registered with it. |
| [0002](/adr/0002-canvas-renderer-translates-or-reports) | The Canvas Renderer translates the CSS it can and reports the rest. |

A new ADR is a new numbered file here, added to this list and the sidebar.
